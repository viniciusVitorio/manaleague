# ManaLeague — campeonatos de Magic com SSDLC

Projeto academico completo para demonstrar **Secure Software Development Life Cycle**. O ManaLeague gerencia campeonatos casuais de Magic com fase todos-contra-todos, ranking, final, disputa de terceiro lugar e placar publico.

Documentação: [arquitetura e módulos](docs/architecture.md) · [ranked ELO/PDL e regulamento](docs/ranked.md) · [SSDLC](docs/ssdlc.md) · [modelo de ameaças](docs/threat-model.md) · [patch notes](docs/patch-notes.md).
